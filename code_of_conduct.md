# Code of Conduct

## Be Cool, Be Kind

This project is all about learning, experimenting, and having fun. Let's keep it that way.

---

## Simple Rules

- **Be respectful** — treat others how you want to be treated
- **Be constructive** — criticism is welcome, but keep it helpful
- **Be patient** — everyone is at a different skill level
- **No drama** — if you see something, say something respectfully

---

## What happens if you don't?

We'll talk to you. If it keeps happening, we'll ask you to leave. Simple as that.

---

## Questions?

If something bothers you, open an issue or reach out privately.

---

**TL;DR:** Don't be a jerk. Help each other. Have fun.
