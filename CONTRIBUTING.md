# Contributing to Witches

Thank you for checking out this project!

---

## Contributing

- Fork the repository
- Create a new branch: `git checkout -b feature/feature-name`
- Write and test your code
- Commit and push to your fork
- Open a pull request

## Style Guidelines

- Follow Clean Architecture principles
- Run migrations: `witches migrate up/down`
- Write tests for new code (where possible)

---

## **Note**

> This project is currently under development and not yet ready for production. Feel free to contribute!
