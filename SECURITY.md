# Security Policy

## Supported Versions

We take security seriously. Here's what we support:

| Version | Supported |
|---------|-----------|
| Latest  | Yes    |
| Older   | No     |

## Reporting a Vulnerability

If you find a security issue, please **don't open a public issue**.

Instead, contact us directly:
- Open a **draft security advisory** on GitHub
- Or reach out privately via [your email or contact method]

We'll respond within 48 hours and work with you to fix it.

## What we expect

- Give us reasonable time to fix the issue
- Don't exploit the vulnerability publicly
- We'll credit you once it's fixed (if you want)

---

**TL;DR:** Found a security hole? Tell us privately. We'll fix it. 🤝
